使用帮助

  • 只统计真实笔迹只有画笔 / 铅笔工具画出的笔迹才计数；在画布上点一下也算 1 笔。
  • 撤销 / 重做撤销不扣数、重做不重复加；撤销后继续画的新笔迹照常 +1。
  • 不计数操作菜单、工具切换、新建图层、滤镜 / 调整、撤销重做等都不会计数。
  • 自动记录新建画布自动创建记录（名字 = 画布名）；Save As / 重命名画布后记录名跟随；与已有记录重名时合并笔数。
  • 上限计数记录与排行榜各最多 1 亿条；单画布笔数上限 1000 亿笔，封顶不再增加。
  • 保持面板打开面板打开时才计数；切到后台、最小化成横条都照常计数，完全关闭面板期间的笔迹不补算。
  • 暂停 / 快捷键当前画布卡片右侧的「暂停」或最小化横条的暂停图标都能暂停/继续；默认快捷键 P（可在「关于」里改键或关闭）。暂停期间不计数，恢复后不补计。
  • 管理记录「清空当前」需点两次确认；记录行内铅笔图标可改名（Enter 保存 / Esc 取消 / 失焦保存）；垃圾桶图标删除需二次确认；排行榜里也能单条删除，或用「全部删除」一次清空（需二次确认）。
  • 排行榜独立排行榜是独立的历史榜：删除「计数记录」里的记录不会删除排行榜；删除排行榜条目（单条或全部删除）也不会删除计数记录。排行榜只有在排行榜里亲自删除才会变化。
  • 数据位置%APPDATA%\AowuCounter\aowu-counter-data.txt（重装 / 升级插件不会清除）。
  • 红绿点顶栏圆点：绿 = 已连接 Photoshop，红 = 未连接（静默重试）。最小化横条圆点：绿 = 当前画布正在记录，红 = 未记录 / 未连接。
